# Angular 17 CRUD Example (Upgraded from Angular 11)

This project has been successfully upgraded from Angular 11 to Angular 17, providing a modern CRUD example with Reactive Forms.

## Upgrade Confirmation
This project has been successfully upgraded from Angular 11 to Angular 17, following the incremental upgrade path through each major version (11→12→13→14→15→16→17).

## Installation Instructions
```bash
# Clone the repository
git clone https://github.com/Rahul-Subramani/angular11.git

# Navigate to the project directory
cd angular11

# Install dependencies
npm install
```

## Running the Application
```bash
# Start the development server
npm start

# The application will be available at http://localhost:4200
```

## Build the Application
```bash
# Build for production
npm run build
```

## Significant Changes
- Updated Angular core packages from v11 to v17
- Updated TypeScript from v4.0.2 to v5.4.5
- Updated RxJS and Zone.js dependencies
- Migrated to the new Angular control flow syntax
- Removed deprecated APIs and patterns
- Improved build performance with the latest Angular CLI
